# TripAura: dummy test project

**This is a demo for testing only. TripAura is not a real business, and nothing here is a real offer or service.**

`index.html` is a Goa weekend trip planner generated by Aleph Alpha's **Kolibri-1** model through the Tesseracted API on 6 Oct 2026. It took 3 rounds of one prompt each: build it, restyle it beachy, then fix the reported bugs. It is published exactly as the model wrote it in round 3, with no edits by a human.

Known issues still present after the fix request (left in on purpose):
- The top "Plan My Weekend" button can't be clicked or tapped.
- The planner's "Plan My Weekend" button is unstyled.
- The footer "Features" link goes nowhere.
- Dona Paula Beach is listed under South Goa (it's near Panjim), and Bom Jesus is called a "Cathedral" (it's a basilica). **Don't use this site to plan a real trip.**
