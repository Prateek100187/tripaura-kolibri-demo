# TripAura: dummy test project

**This is a demo for testing only. TripAura is not a real business, and nothing here is a real offer or service.**

`index.html` was generated in a single prompt by Aleph Alpha's **Kolibri-1** model through the Tesseracted API on 6 Oct 2026. It is published exactly as the model wrote it, with no edits, so people can check the results themselves.

Known issues found in testing (left in on purpose):

- The FAQ accordion doesn't open (the arrow changes, but the answer stays hidden).
- Footer links to `#features` and `#faq` go nowhere.
- Some suggested places are wrong or made up (for example, "Kanak Vrindavan Temple" is in Jaipur, not Indore). **Don't use this site to plan a real trip.**
